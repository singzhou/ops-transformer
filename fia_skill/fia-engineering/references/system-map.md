## Execution chain

```text
PyTorch/PTA
  -> aclnnFusedInferAttentionScoreV*GetWorkspaceSize
  -> generated aclnnInnerFusedInferAttentionScore* executor
  -> opdef + host data dependency
  -> DoOpTilingFusedInferAttentionScore
  -> parser/checkers
  -> SoC template registry and priority/IsCapable
  -> tiling data + tiling key + workspace size + block dim
  -> fused_infer_attention_score kernel entry
  -> compile-time tiling-key dispatch
  -> AIC MM1/MM2 + AIV softmax/vector stages
  -> optional Flash Decoding workspace reduction
  -> attentionOut / optional softmaxLse
```

## Task coordinates

- `bIdx`: request/batch index.
- `n2Idx`: KV-head index.
- `bN2Idx = bIdx * n2Size + n2Idx`.
- `gSize = queryHeads / kvHeads` for GQA.
- `M` or `gS1`: query tokens combined with GQA groups, divided by `mBaseSize`.
- `S2`: KV-token dimension divided by `s2BaseSize`.
- A complete row is one `(bN2Idx, mIdx)` over its valid S2 range.
- Stream-K may divide that row across cores; FD combines the partial softmax/output.

## Actual sequence-length ownership

Current opdef includes `actual_seq_lengths` and `actual_seq_lengths_kv`. The host registration lists their indices in `TilingInputsDataDependency`, so current tiling can inspect their values. Kernel parsers also consume their GM addresses. This dual use is why replacing only a kernel pointer does not make host topology dynamic.

For an optimistic-host/real-device design, name values explicitly:

- `q_exact_host`: exact Q length used for M topology.
- `kv_upper_host`: CPU upper bound used for allocation and conservative topology.
- `kv_real_device`: NPU tensor used to clamp actual S2 work.
- `delta_max`: CPU-known bound such as 16; it is not the exact runtime delta.

## Terminology

- **FIA**: FusedInferAttentionScore.
- **IFA/PFA fallback or reused code**: increment/prompt attention implementation reused by some legacy/general FIA paths.
- **GQA**: multiple query heads share each KV head; `gSize > 1`.
- **FD**: Flash Decoding reduction after S2 cross-core partial attention.
- **Stream-K**: split one attention row along KV/S2 to improve parallelism.
- **S1-out split**: an alternate output/query-direction core assignment; audit separately from FD.
- **PA**: paged attention/block-table KV addressing.
- **tiling key**: compile-time specialization selector generated by host tiling and dispatched in kernel entry.
